# **App Name**: Covenant Keeper

## Core Features:

- Ancestry Management: AncestryAgent: Builds/updates family trees from structured data using Gemini 2.5 to fill in gaps.
- Dispute Mediation: DisputeAgent: Collects testimonies and utilizes Gemini 2.5 to simulate and suggest peaceful resolution paths as a tool. Testimonies processed by FaithAgent.
- Vault Monitoring: VaultAgent: Monitors savings and forecasts usage; simple threshold alerts based on covenant fund values.
- Rule Enforcement: CovenantAgent: Interprets moral rules (JSON); flags conflicts for elder review.
- Rite Logging: RiteAgent: Schedules and logs rites; includes audio log links.
- Diaspora Communication: DiasporaAgent: Sends key updates to remote members; utilizes Firebase notifications.
- Wisdom Guidance: FaithAgent: Offers scriptural references related to decisions, incorporating cultural moral reasoning using Gemini 2.5 as a tool.

## Style Guidelines:

- Primary color: Forest green (#388E3C) evoking growth and stability, essential for community-focused applications.
- Background color: Light beige (#F5F5DC) provides a soft, natural backdrop that complements the green.
- Accent color: Earthy orange (#D35400) is analogous and suggests warmth and activity; ideal for highlights and calls to action.
- Headline font: 'Alegreya', a serif with a contemporary and intellectual feel. Body text: 'PT Sans', a sans-serif providing a balance of modernity and warmth.
- Line icons with moderate detail, symbolizing heritage and progress. Favor icons which communicate tradition while embracing digital integration.
- Clean, card-based layouts that separate agent responsibilities clearly, enabling easy monitoring. Focus on legibility for long descriptions.
- Subtle transitions on data updates. This maintains engagement without being distracting, in order to prioritize information flow.
